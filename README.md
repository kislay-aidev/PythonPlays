## Usage

You can copy any script from this repository, paste it into your preferred code editor, and run it to see how the code works and what output it produces.

For example:

### Turtle Graphics
Run the fractal tree art visualization:
```bash```
python Turtle/Fractal\ Tree\ Art.py

###SciPy Algorithms
Try the shortest path algorithm using NetworkX:
```bash```
python SciPy/Dijkstra’s\ Algorithm\ (networkx).py


###Fun Experiments
Generate a heart shape with turtle graphics:
```bash```
python turtHeart/Heart.py
